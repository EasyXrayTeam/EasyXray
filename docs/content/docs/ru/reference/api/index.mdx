Панель EasyXray предоставляет REST API для автоматизации. Страницы этого раздела
сгенерированы из спецификации OpenAPI самой панели, поэтому они всегда
соответствуют схеме, которую панель действительно отдаёт.

## Пространство имён

Всё, что отдаёт панель, находится под **настроенным базовым путём веб-интерфейса**
(`webBasePath`), за которым следует `easyxray`:

| Поверхность      | Путь                                      |
| ---------------- | ----------------------------------------- |
| Интерфейс панели | `<basePath>/easyxray/…`                   |
| REST API         | `<basePath>/easyxray/api/v1/…`            |
| WebSocket        | `<basePath>/easyxray/ws`                  |
| Спецификация OpenAPI | `<basePath>/easyxray/api/v1/openapi.json` |

С базовым путём по умолчанию (`/`) это означает, например:

```text
GET  /easyxray/api/v1/inbounds/list
POST /easyxray/api/v1/clients/add
GET  /easyxray/api/v1/server/status
GET  /easyxray/api/v1/openapi.json
```

<Callout type="warn">
  **У пространства имён `easyxray` нет алиасов.** Прежние версии панели
  X-UI/3x-ui отдавали эти эндпоинты под `/panel/api/…`; EasyXray **не** отвечает
  на этом префиксе, и совместимый редирект не установлен. Любой скрипт, бот или
  дашборд, написанный под старые пути, придётся перевести на маршруты
  `/easyxray/api/v1/…` выше.
</Callout>

## Аутентификация

Запросы аутентифицируются либо с помощью **сессионной cookie** — она ставится при
входе в панель и называется `easyxray` — либо с помощью **Bearer-токена**:

```text
Authorization: Bearer <token>
```

Создавайте API-токены в разделе **Настройки → Безопасность → API-токен**; они дают
права полного администратора, поэтому храните их так же бережно, как пароль
панели. См. [API-токены](/docs/reference/api/api-tokens).
