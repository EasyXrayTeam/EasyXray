## С X-UI / 3x-ui

**EasyXray не переносит существующую установку X-UI или 3x-ui.** Нет ни шага
обнаружения, ни команды импорта, ни автоматической конвертации. Эти два продукта
намеренно различаются почти во всём, на что пришлось бы смотреть миграции:

| | X-UI / 3x-ui | EasyXray |
| --- | --- | --- |
| Служба и команда | `x-ui` | `easyxray` |
| Конфигурация / база данных | свои пути | `/etc/easyxray/EasyXray.db` |
| Префикс переменных окружения | `XUI_*` | `EASYXRAY_*` |
| HTTP-пространство имён | `/panel/…` | `/easyxray/…` |

Установка EasyXray на сервер, где уже работает X-UI/3x-ui, — это **новая параллельная
установка**, она не заменяет и не обновляет старую. Чтобы переехать, установите EasyXray
с нуля, создайте подключения и клиентов заново и экспортируйте ссылку для подключения
каждого клиента из старой панели, чтобы импортировать её на стороне клиента.
Переиспользовать старый файл SQLite нельзя: схемы различаются.

То же самое касается автоматизации: REST API переехал с `/panel/api/…` на
`/easyxray/api/v1/…`, и у старого префикса **нет алиаса совместимости**. Скрипты, боты
и дашборды, написанные под `/panel/api/…`, нужно обновить.

## Между серверами

Перенос той же самой установки EasyXray на новый сервер сводится к переносу базы данных:

<Steps>

<Step>
### Сделайте резервную копию старого сервера

Скопируйте базу данных (по умолчанию `/etc/easyxray/EasyXray.db`) и ваши сертификаты. См.
[Резервное копирование и восстановление](/docs/operations/backup-restore).
</Step>

<Step>
### Установите EasyXray на новом сервере

Используйте тот же способ установки и совместимую версию. См.
[Установку](/docs/guide/installation).
</Step>

<Step>
### Восстановите базу данных

Остановите панель, разместите базу данных на месте, восстановите сертификаты и
запустите панель. Пересмотрите все настройки, привязанные к конкретному IP или домену.
</Step>

</Steps>

## Между версиями EasyXray

В рамках одного и того же бэкенда обновление обычно сводится к повторному запуску
установщика или загрузке нового образа — панель сама мигрирует свою базу данных.
При переходе между **мажорными** версиями сначала прочитайте
[заметки о релизе](https://github.com/EasyXrayTeam/EasyXray/releases) и сделайте резервную копию.

<Callout type="warn">
  Всегда делайте резервную копию перед любой миграцией и не выключайте старый
  сервер, пока не убедитесь в работоспособности нового.
</Callout>
